3. Hosting und Server-Logfiles

Diese Website wird bei der Hetzner Online GmbH, Industriestr. 25, 91710 Gunzenhausen, Deutschland, gehostet. Die Server stehen in Deutschland. Bei jedem Aufruf verarbeitet der Anbieter automatisch Daten, die Ihr Browser übermittelt:

2. In short

This website is a personal portfolio. The website itself sets no cookies, uses no analytics or tracking tools and embeds no social media plugins or third-party content. 3. Hosting and server log files

This website is hosted by Hetzner Online GmbH, Industriestr. 25, 91710 Gunzenhausen, Germany. The servers are located in Germany. With every request the provider automatically processes data your browser sends:

  • IP address, which Hetzner stores only in shortened form: for IPv4 the last octet is replaced with a random value, for IPv6 the last 88 bits are anonymised
  • date and time of the request
  • requested page or file
  • referrer URL, the page you came from
  • browser type and version, operating system
  • amount of data transferred and HTTP status code

The purpose is to deliver the website and to keep it stable and secure, for example against attacks. The legal basis is Art. 6(1)(f) GDPR; my legitimate interest is the secure and error-free provision of the website. Without this data the website cannot be displayed.

Log files are deleted after 7 days unless they are needed longer to investigate a security incident. A data processing agreement under Art. 28 GDPR is in place with Hetzner. Hosting involves no transfer to countries outside the EU.

All requests to this website pass through the network of Cloudflare, Inc., 101 Townsend St., San Francisco, CA 94107, USA. In doing so, Cloudflare processes the connection data listed above, in particular your IP address.

The legal basis is Art. 6(1)(f) GDPR; my legitimate interest is the secure and fast provision of the website. Cloudflare processes the data on my behalf under a contract pursuant to Art. 28 GDPR.
